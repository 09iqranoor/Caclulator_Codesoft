📟 Stylish Calculator App

This is a fully functional and visually engaging Calculator Web App built using HTML, CSS, and Vanilla JavaScript. 

It supports basic arithmetic operations and includes smooth UI interactions with responsive styling and hover effects.

🔗 Live Demo

https://09iqranoor.github.io/Caclulator_Codesoft/

---

🚀 Features

✅ Real-time calculation and input display

✅ Clear (C) button to reset input

✅ Delete (Del) button to remove last character

✅ Functional arithmetic buttons: +, -, *, /, %

✅ Responsive and animated buttons on hover

✅ Aesthetic background animation s

✅ Stylish UI using modern fonts and shadows

---


🧠 Technologies Used

HTML5

CSS3 (with transitions and keyframe animations)

JavaScript (DOM manipulation and event handling)

Google Fonts
 
Icons8 for decorative SVGs and PNGs
